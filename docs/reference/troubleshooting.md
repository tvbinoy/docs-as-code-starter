Most missing-task questions come down to a date, a filter, or the task's project.

## My task is missing from Today

Check these fields in its project or Inbox:

1. **Status:** Done tasks do not appear in Today.
2. **Due date:** the date must be today or earlier.
3. **Save task:** select it after making changes.

A High priority task without a date does not appear in Today.

## My task disappeared from Inbox

If you changed **Project** to a named project, the task moved there.

Open **Projects**, select the destination, and check the board. Use **Status filter → All** if the task may be complete.

## I cannot see a completed task

Open its project or Inbox and set **Status filter** to **All**.

Today and Upcoming always hide Done tasks. To bring one back, open it, change **Status** to **To do**, and select **Save task**.

## An overdue task is still in Today

This is expected. Today includes unfinished tasks due today **and** overdue tasks.

Choose one of these actions:

| Situation | Action |
| --- | --- |
| The work is finished | Set Status to Done and save. |
| The deadline changed | Set a future Due date and save. |
| The task no longer needs a deadline | Clear Due date and save. |

:::warning Keep useful dates

Do not change a real deadline just to clear Today. Update the plan to reflect the work you actually need to do.

:::

## My edits did not appear

Reopen the task and check the field. Closing the editor without selecting **Save task** discards unsaved changes.

Make the change again and save it. Then check the task in its project before checking Today or Upcoming.

## I cannot save a new task

Check that **Title** contains text. A title is required; notes alone are not enough.

## What should I check first?

> Start in the task's project or Inbox, set the filter to All, and check the saved fields.

Keep the [task-field reference](task-fields.md) handy, or revisit [Workspace basics](../getting-started/workspace-basics.md) for the complete view rules.
