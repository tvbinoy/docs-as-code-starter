Daymark uses the same task information in several views. A task in Today is the same task you see in its project.

## Use the sidebar

| View | What appears | What does not appear |
| --- | --- | --- |
| Inbox | Tasks whose Project is Inbox | Tasks assigned to a named project |
| Today | Unfinished tasks due today or earlier | Done tasks, future tasks, and tasks without dates |
| Upcoming | Unfinished tasks due after today | Done tasks, overdue tasks, and tasks without dates |
| Projects | Your named projects | Inbox |

**Today** and **Upcoming** use the calendar date on your device. Due dates have no time of day.

:::note One task, one home

A task belongs to one project or to Inbox. Its due date can also make it appear in Today or Upcoming; this does not create a copy.

:::

## Read a project board

A project board groups tasks by **Status**:

- **To do:** captured, ready to start.
- **In progress:** work has started.
- **Done:** the task is complete.

![A sample project board with the three status columns.](/img/daymark-board.svg)

Open a task to edit its title, project, status, priority, due date, or notes. Select **Save task** to keep your changes.

## Find completed work

In Inbox and project boards, **Status filter** starts at **Unfinished**. Change it to **All** to include completed tasks.

Today and Upcoming always show unfinished work. To reopen a completed task:

1. Open its project or Inbox.
2. Set **Status filter** to **All**.
3. Open the task.
4. Change **Status** to **To do**.
5. Select **Save task**.

If its date is today or earlier, the reopened task also appears in Today.

## Choose the view for the job

> Capture in Inbox. Plan in Projects. Focus in Today.
