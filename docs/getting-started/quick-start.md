Work through this example to understand Daymark's main workflow. The example uses a project called **Website refresh**.

## 1. Create a project

1. In the sidebar, select **Projects**.
2. Select **New project**.
3. Enter **Website refresh** as the name.
4. Select **Create project**.

The project opens with three columns: **To do**, **In progress**, and **Done**.

## 2. Add your first task

1. In the project, select **Add task**.
2. Enter **Review the homepage heading** as the title.
3. Set **Priority** to **Normal**.
4. Leave **Due date** empty for now.
5. Select **Save task**.

The task appears in **To do**. Because you created it inside the project, its **Project** field is already set to **Website refresh**.

:::tip Use a verb

Start titles with an action: *Review*, *Draft*, *Check*, or *Send*.

:::

## 3. Add a useful note

Open the task, paste this example into **Notes**, and select **Save task**:

```text
Check that the heading explains who the website is for.
Keep it short enough to read at a glance.
```

Notes provide context. The title should still make sense on its own.

## 4. Follow the work

| When | Set Status to |
| --- | --- |
| You have captured the task | To do |
| You have started the review | In progress |
| You have finished the review | Done |

Open the task, choose the status, and select **Save task** after each change.

![Website refresh board showing one task at each stage of work.](/img/daymark-board.svg)

## Check your result

Your project contains a task called **Review the homepage heading**, its notes explain the review, and its status is **Done**.

:::note Looking for the finished task?

In the project, set **Status filter** to **All**. The default **Unfinished** filter hides tasks marked Done.

:::
