Create a task for one action you can finish. Use a project to group several related actions.

## Create a task

1. Open **Inbox** or a project.
2. Select **Add task**.
3. Enter a **Title**.
4. Check **Project**. Choose a named project, or keep **Inbox** if you have not decided where the task belongs.
5. Set a **Due date** if the task needs one.
6. Choose a **Priority** and add **Notes** as needed.
7. Select **Save task**.

New tasks start in **To do**, with **Normal** priority. Only the title is required; project and priority have defaults.

:::tip Capture first, organize later

Use Inbox when you want to record an idea quickly. You can assign it to a project later.

:::

## Write a clear title

| Instead of | Try |
| --- | --- |
| Website | Review the homepage heading |
| Feedback | Send the draft to the reviewer |
| Links | Check the navigation links |

Keep background details in **Notes**:

```text
Review the homepage heading

Notes:
Check the audience, main benefit, and length.
```

This is a planning example. Enter the title and notes in their separate fields.

## Update a task

1. Open the task.
2. Edit the relevant fields.
3. Select **Save task**.

Changing **Project** moves the task; it does not duplicate it. Changing **Due date** updates whether it appears in Today or Upcoming.

:::warning Save before closing

Closing the task editor without selecting **Save task** discards your unsaved edits.

:::

## Complete or reopen a task

To complete a task, change **Status** to **Done** and save. It leaves Today and Upcoming.

To reopen it, find it in its project or Inbox using **Status filter → All**, choose **To do** for **Status**, and save.

For a full list of defaults, see [Task fields](../reference/task-fields.md). If a task disappears from a view, see [Troubleshooting](../reference/troubleshooting.md).
