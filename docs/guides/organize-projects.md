A project groups tasks that contribute to one outcome. Use names such as **Website refresh**, **Move house**, or **Quarterly report**.

## Create a project

1. Select **Projects** in the sidebar.
2. Select **New project**.
3. Enter a short name that describes the outcome.
4. Select **Create project**.

The new project starts with an empty board.

## Move a task from Inbox

1. Open **Inbox**.
2. Open the task you want to organize.
3. Change **Project** to the destination project.
4. Select **Save task**.

The task leaves Inbox and appears in its project. Its status, priority, date, and notes stay the same.

:::note Moving is not copying

Each task belongs to one project or to Inbox. A task due today can still appear in Today after you move it.

:::

## Break an outcome into actions

For a website refresh, start with a short list:

- Review the homepage heading.
- Collect feedback on the draft.
- Check the navigation links.

Avoid one task called **Finish the website** if it contains several separate pieces of work.

## Keep the board useful

| Column | A useful question |
| --- | --- |
| To do | Is this a clear action I can start? |
| In progress | Am I actively working on this? |
| Done | Is the expected result complete? |

Use **Status filter → All** when you want to review the completed work.

:::tip Start with fewer projects

Create a new project when several tasks share an outcome. Keep unrelated ideas in Inbox until they need a home.

:::
