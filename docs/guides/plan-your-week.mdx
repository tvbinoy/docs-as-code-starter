Start with the work you have already captured. You do not need to give every task a deadline.

## 1. Review your projects

Open each active project and check its unfinished tasks:

- Is the next action clear?
- Is its priority still appropriate?
- Does it have a real deadline?

Use **Inbox** to collect loose tasks before you decide where they belong.

## 2. Add dates where they help

Open a task, set **Due date**, and select **Save task**.

| If the task is | A useful choice |
| --- | --- |
| Due on a specific day | Set that date. |
| Important but flexible | Set High priority and leave the date empty. |
| An idea for later | Keep it in Inbox or its project without a date. |

<Callout title="Priority and dates do different jobs">
  Priority expresses importance. A due date determines when an unfinished task appears in Today or Upcoming. Setting High priority alone does not put a task in Today.
</Callout>

## 3. Choose today's focus

1. Open **Today**.
2. Review tasks due today and any overdue tasks.
3. Choose a manageable next action.
4. Open it, change **Status** to **In progress**, and save.
5. When you finish, change **Status** to **Done** and save.

:::tip Leave some breathing room

Choose a few achievable actions. A plan with spare capacity is easier to adjust when something unexpected arrives.

:::

## 4. Adjust the plan

An overdue task stays in Today until you finish it, remove its date, or move its date into the future.

If a task needs more time:

1. Open the task.
2. Choose a realistic new **Due date**, or clear the date.
3. Add a short note if the reason will help you later.
4. Select **Save task**.

## End-of-week review

In each project, choose **Status filter → All** and review what reached Done. Then check the remaining tasks.

> A useful plan makes the next action clear and leaves room to change it.

For exact view rules, see [Workspace basics](../getting-started/workspace-basics.md). For missing or overdue tasks, see [Troubleshooting](../reference/troubleshooting.md).
