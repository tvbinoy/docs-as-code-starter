# Contributing

1. Create a branch from `main`: `docs/<short-description>`.
2. Make your change and preview it with `npm start`.
3. Run `npm run check`.
4. Commit with a prefix (`docs:`, `fix:`, `chore:`) and push.
5. Open a pull request using the template and request another person's review.
6. Address review comments. Merge after approval and passing checks.

Follow the [style guide](STYLE_GUIDE.md).

Daymark is a fictional product. Keep task fields, view rules, and example labels consistent across pages.
Keep course handouts, recordings, transcripts, and private working notes out of the repository.
